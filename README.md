## London Weather Data Visualisation 🌦️
# Project Overview

This application retrieves weather data for London from an open source API. It allows users to look at weather information over time and to see the current weather conditions.
The project uses Matplotlib to create data visualisations alongside JavaScript to support the application's functionality.

# Technologies Used
JavaScript – Makes the webpage interactive.
Matplotlib – Creating temperature vs time graphs.
GitHub – Version control.

# Graph Visualisation

The application uses Matplotlib to generate a graph showing:

X-axis: Time
Y-axis: Temperature (°C)

## Getting Started
1. Clone the repository

`git clone https://github.com/kimlxnh/weather_dataOps`

2. Navigate into the project folder with `cd`

3. Install dependencies

For Matplotlib:

`pip install matplotlib`

4. Run the application with `npm run dev`
